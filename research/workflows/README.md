# Retired workflow definitions

This directory preserves GitHub Actions definitions that were useful during VeriQueue's research and optimization phase but are intentionally **inactive** on current `main`.

GitHub executes workflows only from `.github/workflows/`; keeping historical definitions here preserves provenance without presenting research campaigns as current product CI.

Files are preserved byte-for-byte. Consequently, they may reference historical paths, branch names, or workflow names. Use the corresponding historical commit/PR for exact reproduction rather than treating these files as maintained automation.
