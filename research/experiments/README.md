# Retired experiment sources

These files were previously kept beside active benchmarks and tooling on `main`. They were moved here during repository productization because they exist to reproduce historical optimization experiments rather than to build, test, or benchmark the shipping VeriQueue surface.

The source files are preserved byte-for-byte. Retired workflow definitions are preserved separately under [`../workflows/`](../workflows/).

For an exact runnable historical environment, check out the commit or PR recorded by the experiment. Archived workflow files can reference their original repository paths by design; this archive does not rewrite historical execution context.
